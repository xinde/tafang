# 余烬守卫 · Emberwatch

[手机或电脑直接玩](https://xinde.github.io/tafang/)

一款复古像素塔防游戏。敌人从红旗出发，沿土路攻向城堡。你可以先看下一波的敌人，再决定把金币花在新守卫、全局强化，还是留到下一波。

## 开局与换关

第一次从首页进入，会在苔桥前哨、风车麦田和潮汐灯港中随机开局。以后默认从全部 12 张地图抽取，也可以在「战役地图」改选「同难度随机」。各个抽取范围单独记轮次，抽完本轮再洗牌。通关后点「随机下一关」继续，想自己挑场景可打开「战役地图」。重试会保留原地图。要分享指定关卡，可以复制下表中的链接。

1. 在「部署守卫」选弩手，点弯道内侧带加号的石台。一座塔就能照顾两段路。手机按住石台，浅绿色虚线会标出真正打得到的路段。射程够不到路时会先提醒，再点同一石台才会花钱部署。点已部署的守卫，可切换「优先领头」和「优先最近」。
2. 点「开始第 1 波」。击败敌人会获得金币和技能能量。两波之间可以整备，也可以提前迎战，最多多拿 8 金币。
3. 想提高全队攻击力、攻速或射程时，打开「全局强化」。城堡还有耐久并守住最后一波，就能进入下一关。

每关的可选目标单独记录，普通通关后仍可重打争取勋章。四卫挑战按整局同时驻场的最高人数计算，零漏怪按实际进入城堡的敌人数计算。

第二波清空后，战场会暂停，让你选一项持续到结算的战术。

| 战术 | 效果 |
| --- | --- |
| 碎冰炮弹 | 重炮命中受霜晶减速的目标，消耗这次减速，溅射半径扩大 75%。 |
| 连射弩 | 同一弩手连续命中同一目标，第三箭的基础伤害翻倍。 |
| 机动工坊 | 主动出售守卫的返还比例从 50% 提高到 80%。 |

手机长按已部署的守卫，或开启「出售守卫」后点它即可出售。电脑可用数字键 `1` 至 `7` 选守卫，`P` 暂停。战役地图会显示当前浏览器保存的各关最佳通关评级。

击杀敌人攒满 100 能量后，战斗中可选四种技能之一。`Q` 放陨石，`W` 冰冻敌人，`E` 让本波余下的击杀奖励翻倍。`R` 发动「抢修」，立刻把城堡和场上所有存活守卫的耐久回满。首领会标记最多两座守卫，蓄力两秒后各冲击 30 耐久。石台亮环时可以用冰冻打断，也可以受击后抢修。设施全部完好时会保留抢修能量。手机直接点战场技能按钮即可。

顶部的「音乐」和「音效」可以分别开关，选择会在换关和刷新后保留。像素风循环曲[《城墙上的灯》](assets/audio/watchfire.mp3)在第一次操作后按需加载，手动暂停或切到后台会暂停播放。

## 答题强化

题库面向小学四至六年级，共 **180 道纯文字四选一**。12 个主题覆盖历史、文学、汉字、运算、几何、逻辑与数据、英语、地理、生态、物理实验、地球与太空、音乐与美术。看图例、辨方向、读统计数据的题也会把所需条件写进题干。

在「全局强化」里选择答题难度，它和战役难度独立。轻松、标准、挑战各有 60 道题，都覆盖 12 个主题。轻松每题 40 至 45 秒，标准 20 至 35 秒，挑战 20 至 30 秒。同一关内各档独立抽题，一轮内不会重复。

答题时战斗暂停。答错或超时会显示正确答案和一句解析，可以读完后免费再答，也可以返回战场。只有答对并成功强化时扣金币。

## 本地试玩

游戏源码和测试在 `main`，线上版本从 `gh-pages` 发布。在本机试玩只需要 Git 和 Python 3。

```sh
git clone https://github.com/xinde/tafang.git tafang-play
cd tafang-play
python3 -m http.server 4178 --bind 127.0.0.1
```

服务启动后打开[本地游戏](http://127.0.0.1:4178/)。

## 维护题库

题目都在 [config/quiz.json](config/quiz.json)。每组的 `timeLimit` 是默认答题秒数，单题可以覆盖。每题用 `difficulty` 标记轻松（`easy`）、标准（`standard`）或挑战（`challenge`），并在 `explanation` 中写明推理或记忆要点。写题时把条件写全，准备四个不同的选项，把唯一正确选项的下标填入 `answer`。下标从 0 开始，下面这个例子中「8 页」是第二项，所以填 1。

```json
{
  "q": "从第 18 页读到第 25 页，两端都读，一共读了几页？",
  "options": ["7 页", "8 页", "9 页", "6 页"],
  "answer": 1,
  "difficulty": "standard",
  "explanation": "首尾两页都算在内，所以是 25 − 18 + 1 = 8 页。"
}
```

测试放在 `main` 分支。修改题库后，可用 Node.js 22 或更新版本运行 `npm test`，再将验证过的题库同步到 `gh-pages`。
